## 研究方法與證據限制

1. PvP 精確 rank/score/moveset 直接取自 PvPoke 官方 GitHub repository JSON，不把搜尋摘要當證據。
2. PvE、Mega、Max 與道館直接開啟 GO Hub Database 原始頁。
3. 已開啟 Pokebattler 的 Venusaur/Charizard attacker pages；其資料是依 raid boss/moveset 聚合，不是全域 tier，且本次動態表格分別出現 Shadow Mamoswine/Mega Blaziken，無法可靠歸因，因此未虛構「Pokebattler 全域排名」。
4. 淨化版在 PvPoke 沒有獨立 speciesId；generic entry 可能把 Return 納入最佳招式。無法拆分時一律 `NEEDS_REVIEW`。
5. Dynamax 前階只可進化為同一 Dynamax 家族，不能把普通或 Dynamax 舊個體當成 Gigantamax。

## 各家族保留方向

### #001～#003 妙蛙種子家族

- **可信價值**：Shadow Venusaur PvE、Mega Venusaur、GMax Venusaur；一般 Venusaur 有中段 PvP/過渡 PvE。
- **前階**：只在要進化成上述目標時保留；Bulbasaur 本體 GL #1040，漂亮高 IV 不足以單獨成為保留理由。
- **招式**：Frenzy Plant 為 legacy/event/Elite Charged TM；current PvPoke 推薦 Sludge 作第二蓄力技。
- **IV**：PvP 看指定聯盟實際 IV Rank；暗影 PvE 優先高攻/15 攻；Mega/Max 保留少量高 IV/15 攻。

### #004～#006 小火龍家族

- **可信價值**：Shadow Charizard Fire A+ #12、Mega Y Fire #1、Mega X Fire #6、GMax Charizard Fire #2。
- **PvP**：current open rank 僅中後段；不要用「曾經強」取代 current 數據。
- **招式**：Blast Burn 必要。GL current 推薦 Ember/Blast Burn/Air Cutter，UL current 推薦 Dragon Breath/Blast Burn/Air Cutter；Wing Attack/Dragon Breath/Ember 均要確認 legacy 取得狀態。
- **保留**：依版本分開，少量高品質 Mega/Max/Shadow；普通大量囤積沒有證據。

### #007～#009 傑尼龜家族

- **最明確 PvP**：一般 Blastoise GL #51、UL #22；Shadow GL #181、UL #77。
- **PvE**：一般 Water D #59；Shadow Water A #27；Mega Water S #4。
- **Max**：DMax F #17、GMax D #7，current 攻擊與坦克均有更好替代，不能因是 Max 就直接 KEEP 大量。
- **招式**：Hydro Cannon 必要；GL/UL 一般版 current 推薦 Rollout/Hydro Cannon/Skull Bash。

### #010～#012 綠毛蟲家族

- 普通/Shadow Butterfree 的 GL 與 PvE 都極低。
- DMax Butterfree C #4；GMax 頁面 tier 與 prose 衝突，必須 `NEEDS_REVIEW`。
- Bug Bite 是 legacy，但具備後普通 PvE仍是 F Tier；不能因特殊招式就自動 KEEP。

### #013～#015 獨角蟲家族

- 一般/Shadow Beedrill current GL #472/#483，UL #720/#717，屬條件式或特殊環境用途。
- Mega Beedrill 是主要理由：Poison S #3、Bug S #7；保留少量高 IV/15 攻候選。
- PvP Drill Run 在 GO Hub 標為 legacy；需搭配 Poison Sting/X-Scissor。
- GO Hub current Dynamax list 未列 Weedle/Kakuna/Beedrill；仍待官方來源確認「未推出」。

## 來源衝突與高風險判斷

1. **Little Cup rank drift**：GO Hub 與 current PvPoke raw JSON 差距明顯。特殊盃一律附版本且降 confidence。
2. **GMax Butterfree**：同頁 #1 S 與「可能不值得培養」互相衝突，直接 `NEEDS_REVIEW`。
3. **Mega Charizard Y Flying**：頁面列 Flying S #7，但 prose 明說 Flying 定位被壓過且不建議；只用 Fire #1 作主要保留理由。
4. **Pokebattler 動態表**：頁面主體與表格物種不一致，未匯入其 rank/points。未來必須固定 boss、level、weather、friend bonus、party size 才能保存 estimator/TTW/deaths。
5. **Purified**：Return 被 generic species entry 使用時才能辨認；其餘 normal/purified 無法拆分 exact rank。

## NEEDS_REVIEW 清單

- 當季火箭隊逐物種/逐版本用途：未取得可重現排名，不能拿 PvE/PvP 直接代替。
