# Pokémon GO #001～#030 官方資料研究筆記

- 查閱日期：2026-07-15
- 研究範圍：Pokémon GO 官方網站與官方新聞；不含 PvPoke、Pokebattler、GO Hub 或搜尋摘要作為結論證據。
- 判讀原則：找不到官方頁面時標記 `NEEDS_REVIEW`，不把『未搜尋到』推論成『未推出』。
- 時態原則：活動頁面可確認曾推出，不必然代表目前可取得。

## 重要結論

1. #001～#009 的 Dynamax 個體已由官方確認；官方並明確說明，從 Max Battle 捕捉的個體及其進化可 Dynamax。一般舊個體不會因此自動成為 Dynamax 個體。
2. Gigantamax Venusaur、Charizard、Blastoise、Butterfree、Pikachu 已有官方首次登場證據。
3. Mega Venusaur、Charizard X/Y、Blastoise、Beedrill、Pidgeot 已有正式推出證據。
4. Mega Raichu X/Y 預定 2026-07-18 首次登場；本批查閱日為 2026-07-15，故只能記為 `ANNOUNCED_NOT_YET_RELEASED`。
5. 官方明示 Shadow Pokémon 不能 Mega Evolve；普通、Shadow、Purified 與 Mega 必須分開建模。
6. Gigantamax Pikachu 官方明示不能進化；不可沿用一般皮卡丘的進化判斷。

## 尚待人工確認

- 本輪官方來源未覆蓋所有普通型態、暗影型態及進化路徑；空缺均維持 NEEDS_REVIEW。
- 官方活動文章可證明某型態曾出現，但通常不能證明目前可取得。資料模型應區分 everReleased 與 currentAvailability。
- 未取得逐物種的官方『不存在／未推出』清單，因此未將搜尋不到的 Mega、Dynamax、Gigantamax 或 Shadow 填成 NOT_RELEASED。
- 招式繁中名稱尚未逐筆由 zh-TW 官方頁面覆核；英文原名與活動取得條件已留存。
- 阿羅拉雷丘在官方頁面以團體戰出現；本輪未找到官方頁面明示其不可由皮卡丘進化，取得方式仍需覆核。
- Mega Raichu X/Y 的 2026-07-18 首次登場晚於本批 2026-07-15 查閱日，因此只能標為 ANNOUNCED_NOT_YET_RELEASED。
- Gigantamax Pikachu 官方明示無法進化；不可把一般皮卡丘的進化路徑套用至該個體。

普通型態逐名證據不足：`011-kanto`, `020-kanto`, `022-kanto`, `024-kanto`。

JSON Review Queue 共 213 筆；其中包含所有未確認戰鬥版本，因此數量刻意偏多，供主資料匯入時保守處理。
